# 文件加密工具 WebUI

这是一个现代化、响应式的Web管理界面，用于控制文件加密工具。该工具支持多种加密算法，具有直观的用户界面和强大的功能。

## ✨ 功能特性

### 🎨 界面设计
- 💎 **全新现代化科技感设计** - 深蓝/紫黑色调，蓝青色+紫色渐变
- 🪟 **玻璃态设计** - 半透明背景、24px模糊效果、微妙边框
- 🌟 **粒子动画背景** - 漂浮彩色粒子，增强科技感
- 🎯 **完美响应式布局** - 适配手机、平板和电脑
- 🔮 **精美交互动画** - 按钮波纹、卡片上浮、进度条闪光等

### 📊 核心功能
- 🔒 **三种加密算法** - AES-256、Blowfish、XOR
- 📁 **完整映射表** - 显示原始文件、加密文件、MD5、盐值、密码、加密类型等8个信息列
- ⚡ **实时进度跟踪** - 百分比显示、渐变进度条
- 📜 **实时日志** - 自动滚动、清除功能
- 🔍 **智能搜索** - 支持按文件名、密码、盐值、加密类型等过滤
- 🔑 **密码管理** - 显示/隐藏切换、安全输入框

### 🛠️ 操作控制
- ▶️ 一键加密/解密操作
- ⏹️ 随时停止当前操作
- 💾 配置保存和加载
- 🔄 实时数据更新

## 🚀 快速开始

### 1. 启动服务
```bash
./encrypt -webui
```

### 2. 访问界面
在浏览器中打开：**http://localhost:9394**

### 3. 开始使用
1. 在"配置管理"页面设置密码和选择加密算法
2. 设置目标路径（要加密的文件夹）
3. 点击"保存配置"
4. 在"控制台"页面点击"开始加密"
5. 加密完成后，在"映射表"页面查看加密文件信息

## 📖 详细使用指南

### 控制台页面
- 📊 **数据统计** - 显示已加密文件数、监控路径数、安全等级
- ⚡ **操作按钮** - 加密、解密、停止按钮
- 📈 **实时进度** - 显示当前操作进度百分比
- 📝 **系统日志** - 实时显示操作日志信息

### 配置管理页面
- 🔐 **加密密码** - 输入安全密码（建议8位以上）
- 🛡️ **加密算法** - 选择 AES-256（推荐）、Blowfish 或 XOR
- 📂 **目标路径** - 设置要加密的文件夹路径（支持多行）
- 🎯 **混淆后缀** - 设置加密文件的后缀名（默认 .dat）
- 💾 **存储路径** - 设置映射表存储位置

### 映射表页面
- 🔍 **搜索功能** - 快速搜索加密文件
- 📋 **完整信息** - 查看所有加密文件的详细信息
- 💾 **数据展示** - 包含原始路径、加密路径、MD5、盐值、密码、加密类型等

## 使用方法

### 命令行参数

```
-encrypt    启动加密模式
-decrypt    启动解密模式
-webui      启动WebUI管理界面
-help, -h   显示帮助信息
```

### 启动WebUI服务

1. 启动WebUI服务：
   ```bash
   ./encrypt -webui
   ```

2. 在浏览器中访问：http://localhost:9394

### 命令行模式

```bash
# 加密模式
./encrypt -encrypt

# 解密模式
./encrypt -decrypt
```

## 构建和部署

### 自动构建
项目包含自动化的构建脚本，支持跨平台编译：

```bash
# 构建所有平台的二进制文件
./build.sh

# 构建特定平台
./build.sh linux amd64 encrypt-linux-amd64
```

支持的平台：
- Linux (amd64)
- Windows (amd64)
- macOS (amd64, arm64)
- Android (arm64)

### 配置文件
工具使用YAML格式的配置文件 `encrypt_config.yaml`：

```yaml
password: your_password_here
encrypt_type: aes
target_paths:
  - /path/to/target1
  - /path/to/target2
obfuscate_suffix: .dat
obfuscate_name_length: 12
map_filename: .app_encrypt
lock_filename: .encrypt.lock
map_storage_path: /path/to/map/storage
```

## 注意事项

- 请确保配置文件中的密码足够复杂以保证安全性
- 加密/解密操作可能需要较长时间，请耐心等待
- 操作过程中请勿关闭浏览器或刷新页面
- 映射表会自动保存，用于解密时恢复原始文件名
- 支持断点续传，可以在中断后继续操作
